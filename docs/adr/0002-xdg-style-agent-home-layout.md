# Use an XDG-style layout for autonomous agent homes

Each autonomous agent has an Agent System Home mounted as `/home/agent`, while Pi-specific configuration and durable agent memory live under `/home/agent/.config/pi/agent` as the Agent Harness Home. This keeps the agent's Unix-like home distinct from the Pi harness repository, lets `work/`, `playgrounds/`, and `tmp/` behave like normal home directories, and allows sessions to live in a separate private repository at `/home/agent/.config/pi/sessions`.

This layout was chosen because nested Pi launches from inside the Bubblewrap containment can still behave like normal Pi runs: the launcher sets `HOME=/home/agent`, `PI_CODING_AGENT_DIR=/home/agent/.config/pi/agent`, and `PI_AGENT_*_DIR` variables, so Pi and agent-authored tools can consistently find the harness home, memory, world, decisions, and sessions. The structure also mirrors normal Linux/XDG expectations, making the agent feel like a real user account without requiring a real OS user per agent.
